# mobile-web-app

Wydzielona aplikacja mobile-web z repo `iclean-room`.

## Co zostalo skopiowane
- `src` (aktualny kod mobile React)
- `stary_skrypt_mobile` (archiwalne pliki z logik)
- `dataconnect-generated` (SDK Data Connect uzywane przez mobile)
- `mobile.html` i `README_SOURCE.md` (oryginaly z poprzedniej lokalizacji)

## Uruchomienie lokalne
1. `cd mobile-web-app`
2. `npm install`
3. skopiuj `.env.example` do `.env` i uzupelnij zmienne
4. `npm run dev`

## Build
- `npm run build`
- `npm run preview`
